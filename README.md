## `WHO IS OLD-RX?`

**Old-Rx** is the identity behind **RX-Development**.  
This profile is intentionally built as a **live developer HUD** rather than a plain résumé.

Core loop:

> **Understand → Design → Build → Test → Debug → Deploy → Observe → Improve**

The important visual experience is stored in **local SVG files inside the profile repo** so the profile remains strong even if third-party stat generators fail.
