## `WHO IS OLD-RX?`
**Old-Rx** is the identity behind **RX-Development**.

This profile is designed to feel like a **developer HUD / system dashboard**, not a plain résumé. The goal is to combine strong visual identity with actual engineering structure.

> **Understand → Design → Build → Test → Debug → Deploy → Observe → Improve**

The most important visuals are stored as **local SVG files inside the repository**, so the profile stays more stable and more custom.

# `04 // ENGINEERING CORE`
<div align="center">
<img width="100%" src="https://raw.githubusercontent.com/Old-Rx/Old-Rx/main/assets/security-shield.svg" alt="Security Shield"/>
<img width="100%" src="https://raw.githubusercontent.com/Old-Rx/Old-Rx/main/assets/code-rain.svg" alt="Code Rain"/>
</div>

### `Architecture before complexity`
A clean structure is more valuable than a huge random stack.

### `Performance is part of design`
Performance includes render cost, payload size, query shape, network behavior and caching.

### `Security belongs inside the system`
Validation, authorization, safe defaults, secrets handling and observability are architectural concerns.

### `Production is its own environment`
A successful local build is not the same as a stable production runtime.
