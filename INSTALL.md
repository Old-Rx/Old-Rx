# Install

Copy these files into the root of your `Old-Rx/Old-Rx` profile repository:

- `README.md`
- `assets/hero-glitch.svg`
- `assets/rx-minigame.svg`
- `assets/system-scan.svg`
- `assets/red-signal-stream.svg`
- `assets/rx-wave.svg`
- `.github/workflows/snake.yml`

After pushing to `main`, the README's custom animations resolve from your own repository.

The contribution snake workflow writes its SVG to the `output` branch.
