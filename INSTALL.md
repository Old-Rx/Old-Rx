# Install — Inferno Edition

Upload these items into the root of your `Old-Rx/Old-Rx` repository:

- `README.md`
- `assets/`

Required structure:

```text
Old-Rx/Old-Rx
├── README.md
└── assets/
    ├── hero-inferno.svg
    ├── rx-minigame-inferno.svg
    ├── system-scan-inferno.svg
    ├── threat-radar.svg
    ├── red-signal-stream.svg
    ├── boss-bar.svg
    ├── rx-commit-hunter-overdrive.svg
    └── footer-wave.svg
```

No GitHub Actions needed.
No output branch needed.
All major animations are local SVG assets loaded from your own repo.
