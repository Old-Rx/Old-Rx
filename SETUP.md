# HYBRID MAX — SETUP

This package uses two layers:

1. **GitHub Profile README**
   - Animated GIFs
   - Technology icons
   - Repository links
   - Works directly on your GitHub profile

2. **GitHub Pages interactive site**
   - HTML / CSS / JavaScript
   - Canvas particles
   - Interactive RX-DEVELOPMENT mini-game
   - Terminal typing
   - Animated technology matrix
   - Radar
   - Delivery pipeline
   - Overdrive mode
   - Production boss

## Enable GitHub Pages

After uploading everything:

1. Open `Old-Rx/Old-Rx`
2. Go to **Settings**
3. Open **Pages**
4. Under **Build and deployment**, choose **Deploy from a branch**
5. Branch: `main`
6. Folder: `/docs`
7. Save

The interactive site should be available at:

`https://old-rx.github.io/Old-Rx/`

## Important

If GitHub Pages gives you a different URL, replace the two `old-rx.github.io/Old-Rx/` links inside `README.md`.
